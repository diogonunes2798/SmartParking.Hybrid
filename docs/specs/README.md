# Especificações

Índice das especificações do protótipo, no formato do comando `/spec` do *kit* (dotnet-claude-kit).

- Cada especificação fica em `docs/specs/<NNN>-<slug>.md`, numerada por ordem de criação.
- Ciclo de vida do estado: Rascunho (*Draft*) → Em revisão (*In Review*) → Aprovada (*Approved*, com data).
- A implementação só começa a partir de uma especificação aprovada; cada critério de aceitação (`AC-n`) tem um teste com esse nome.
- Cada especificação indica os casos de uso (UC), os requisitos funcionais (RF) e os requisitos não funcionais (RNF) da tese a que responde; a ligação fica registada em [`docs/RASTREABILIDADE.md`](../RASTREABILIDADE.md).
